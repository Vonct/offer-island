# Offer Island · 求职小岛

本地优先的求职工作台，支持 Agent 接入与 macOS 桌面小岛。**v0.3.1**。

奶油纸色、手帐式卡片和彩色阶段标签。把投递、日程和面试经验留在自己的设备上。

## 现在能用什么

- 职位手动增删改、搜索筛选；可填写岗位 JD，点击公司名下方的职位名称打开 JD 浮动卡片；保留招聘平台原始状态和来源。
- 月历、今日待办、会议链接、完成标记。
- 岗位行内打开的面经卡片：面试轮次、问题、复盘、下次准备。
- JSON / CSV 导入收件箱、预览新增与更新、逐条核对、去重、全量导出。
- 文本草稿：提取明确标注的公司、职位、状态和投递日期，未识别字段留空，核对后保存。
- macOS 截图 OCR：使用 Apple Vision 在本机提取文字，再进入投递草稿核对；不内置大模型自动理解任意招聘页面。
- 最近 20 次操作可撤销、最近 500 条修改历史、跨窗口版本冲突保护。
- MCP：读取投递 / 今日安排、写入投递 / 日程、预览 / 提交导入、撤销。
- macOS 刘海小岛：自动读取内屏刘海几何，收起时显示左右两翼摘要，悬停或点击向下展开；无刘海屏幕回退为顶部胶囊。包含可爱木鱼、合成敲击音、待办轮播、倒计时、免打扰和菜单栏收起。

## 开始使用

### 网页本地模式

无需依赖，使用静态服务器：

```sh
python3 -m http.server 8780 --bind 127.0.0.1 --directory web
```

打开 http://127.0.0.1:8780/ 。`?demo` 是隔离的虚构示例。这个模式使用浏览器存储；未登录时没有桌面 OCR 或跨设备同步。浏览器打开的小岛是普通弹出窗口，不会置顶。

### SQLite + Agent 模式

需要 Node.js 24 或更高版本：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:8780/ 。页面通过本地服务保存到 SQLite，MCP 和桌面小岛使用相同数据。默认数据库：

```text
~/Library/Application Support/Offer Island/offer.sqlite
```

可用 `OFFER_DB` 更改数据库位置，`OFFER_PORT` 更改 Web 服务端口。此服务仅绑定 loopback，并检查 Host、Origin 和请求标识，不用于公网部署。

### macOS 应用

需要 macOS、Xcode Command Line Tools、Node.js 24+：

```sh
npm run build:mac
open "dist/Offer Island.app"
```

构建会把本机架构的 Node 运行时放入应用。启动应用后自动启动本地 SQLite 服务（18783 端口），显示小岛，点击右上角 ↗ 在默认浏览器打开本地工作台。顶部菜单栏图标左键直接显示 / 隐藏小岛，右键打开完整菜单；小岛上的“—”或“收起到菜单栏”也可隐藏面板。退出应用时停止自有服务。

这是本地 ad-hoc 签名构建，**未做 Apple Developer ID 签名、公证或 App Store 发布**。当前构建基于本机架构 / SDK，未宣称支持所有旧版 macOS 或 Intel Mac。

默认不登录即可使用，桌面数据保存在 SQLite，在线网页数据保存在当前浏览器。需要多设备同步时，分别登录同一账号；新注册需要邀请码。登录后可预览本机记录或导入 JSON 备份，确认后仅新增到云端，原本地数据保留。

## Agent 配置

见 [MCP 接入](docs/MCP.md)。MCP 使用 stdio，不依赖网页是否打开。Agent 和人工写入共用 `web/core/model.mjs` 验证与迁移规则。并发写入必须携带最近读取的 revision。

## 数据与备份

网页旧版存储会在第一次打开时迁移，旧键保持不动。导入默认只新增；允许覆盖已有字段时需勾选选项。日程必须有明确日期，无日期的面试通知留在职位的下一步中。

全量备份包含投递、日程、面试手记和历史。恢复通过导入合并，不清空现有记录；撤销栈不导出。清空浏览器存储会丢失未备份的数据。

小岛提供可见倒计时，不是系统级定时通知；关闭应用后不会弹提醒。提供可选云同步；尚无邮件账号接入、开机自启、自动安装更新或内置聊天模型。

### 桌面入口调整
网页不再提供浏览器小岛入口。桌面应用启动后仅显示小岛和菜单栏；点击小岛右上角 ↗ 或菜单栏“打开网页版”，在默认浏览器打开本机工作台。内部服务随应用自动启动，网页与小岛共用 SQLite。此本机工作台并非 Netlify 公网页面；可以主动登录开启云同步，详见 [云同步说明](docs/CLOUD.md)。

### 本地安装包
运行 `bash scripts/package-mac.sh` 生成 `dist/Offer-Island-0.3.1.dmg`，打开后将应用拖入 Applications。运行时无需另装 Node 或数据库，无需账号。安装包仅含本机架构应用，不含个人数据；仍为未公证的本地测试版。未登录时 Netlify 与桌面数据独立，可用 JSON 导入导出转移；登录同一账号后使用云端工作区，约 3 秒刷新。

### 检查更新
菜单栏 ✳ → 检查更新，读取 GitHub 最新正式 Release。发现新版后可打开发布页手动下载，退出旧应用后替换 Applications 中的应用。数据库保存在 Application Support，替换应用不会清空数据；建议升级前导出备份。检查仅在用户点击时联网，不上传投递或日程。
