# Offer · 求职小岛

本地优先、Agent 可操作、带一点可爱陪伴感的求职工作台。

**状态：早期网页原型，不是完整桌面产品。** macOS 顶部小岛、电子木鱼、MCP 和职位手动录入尚未实现。

## 运行

无需构建或安装依赖：

```sh
python3 -m http.server 8780 --bind 127.0.0.1 --directory web
```

访问 http://127.0.0.1:8780/ 。使用 `?demo` 查看虚构示例。正式模式从空白数据开始。

## 已有功能

- 日程月历：新增、编辑、完成、删除、关联已有职位。
- 日程 JSON 导出 / 导入（按 ID 添加，不覆盖已有项）。
- 职位表展示及状态、链接编辑；新用户可通过示例查看效果，正式的职位录入入口待开发。
- 当前浏览器本地保存。不同域名和浏览器不共享数据；没有云同步或后台提醒。
- 演示模式修改不写入正式存储。
