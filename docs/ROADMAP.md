# v0.3 交付范围

## v0.1 — 可独立使用

- [x] 手动增删改职位、搜索、状态筛选和彩色状态选择器
- [x] 月历、日程增删改、完成标记
- [x] 岗位行内面经入口、历史面经卡片与编辑
- [x] 共享数据模型、原始状态 / 来源、修改历史
- [x] 全量 JSON 导出、合并导入、数据校验、旧版迁移、跨窗口冲突保护

## v0.2 — Agent 接入

- [x] stdio MCP：查询、投递写入、日程写入、导入预览、提交和撤销
- [x] JSON / CSV 收件箱、逐条核对、去重与覆盖选择
- [x] 粘贴文本的显式字段提取与人工补充
- [x] macOS 本地 OCR 提取截图文字，或外部 Agent 提取结构化数据
- [x] 人工与 Agent 共用验证、SQLite 事务、版本检查

## v0.3 — macOS 桌面陪伴

- [x] Swift AppKit NSPanel + WebKit 主窗口，与 MCP 共用 SQLite
- [x] 可爱电子木鱼：点击动画、合成敲击声、声音开关
- [x] 今日待办轮播，悬停暂停；30 分钟内下一项优先固定
- [x] 展开、倒计时、完成、会议链接、免打扰、隐藏与菜单栏恢复
- [x] 无刘海依赖，普通屏幕顶部放置；菜单提供位置重置
- [x] 本机 .app 构建脚本和 ad-hoc 签名

## 后续

- Apple Developer ID 签名、公证、Intel / 旧版 macOS 验证与自动更新
- 系统通知、开机自启、跨设备同步
- 内置模型对任意格式招聘截图自动分条理解（当前使用 OCR + 核对或用户自己的 Agent）
